## Featured Work

### [capulus-core](https://github.com/pkr-lab/capulus-core)

Fully automated, GitOps-driven infrastructure on k3s. Production-ready home server platform demonstrating enterprise-grade infrastructure patterns at scale:

- Fully automated infrastructure provisioning with Ansible
- GitOps workflow with ArgoCD for declarative deployment
- Zero-trust networking with Tailscale VPN integration
- Single-node Kubernetes (k3s) for resource-efficient orchestration
- Complete separation between configuration management and runtime

This project serves as a reference implementation for infrastructure automation principles.

### [PowerShell](https://github.com/pkr-lab/PowerShell)

Administration and automation scripts for Windows systems and infrastructure management.
